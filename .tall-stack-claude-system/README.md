# TALL Stack · Sistem Claude AI

## Cara Pasang
1. Copy SEMUA isi folder ini ke **root proyek Laravel** Anda
2. Buka Claude → lampirkan `CLAUDE.md`
3. Ketik `/init` untuk mulai

## Isi Folder
```
CLAUDE.md                ← Lampirkan ke Claude setiap sesi baru
.claude/commands/        ← Instruksi slash commands (jangan diedit)
tasks/progress.md        ← Simpan progres antar sesi
tasks/lessons.md         ← Database error (diisi otomatis oleh Claude)
```

## Slash Commands
| Command | Fungsi |
|---|---|
| `/init` | Mulai proyek baru (onboarding) |
| `/new-page` | Buat halaman baru |
| `/new-component` | Buat komponen Blade/Livewire |
| `/fix-ui` | Perbaiki & percantik tampilan |
| `/form` | Buat form Livewire + validasi |
| `/debug` | Debug error + catat pelajaran |
| `/review` | Review kode + saran peningkatan |
| `/deploy-check` | Cek kesiapan sebelum upload hosting |
